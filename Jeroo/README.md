The goal of the game is for Jeroo to collect all the flower and place them in given point, avoiding the nets and before the time runs out.
<br>
Use WASD or Arrow keys to control
<br>
All the assets used including audios and pictures are present in 'assets' folder. Code can be viewed in 'Jeroo.py'. You can download the executable 'Jeroo.exe' to play the game.
