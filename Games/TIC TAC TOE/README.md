# TIC TAC TOE WITH MINIMAX

Tic Tac Toe in python using minimax in terminal. 

## Details
Play Tic Tac Toe against the computer. You play as 'O' and the computer is 'X'. The computer
makes moves using the minimax algorithm, i.e. It explores all the possible states after a 
move and picks the best one.

`Made in Python`
