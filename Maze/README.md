# Maze

An implementation of solving a maze using BREADTH FIRST SEARCH and DEPTH FIRST SEARCH

## How To Use

- Run the `maze.py` file
- Use arrow keys to traverse through the mazes
- Click the button at top to toggle between BFS and DFS

Note: Most of the mazes look the same in BFS and DFS but BFS always ensures the shortest path.
